## What this is

Trove is a fresh-start derivative of the abandoned `averygan/reclip` project: a self-hosted, browser-based downloader for videos and audio from YouTube, TikTok, Instagram, Vimeo, and ~1000 other sites, powered by yt-dlp + ffmpeg.

Phase 1 ships, in one go:

1. **All 19 audit items** from the security/bug review (RCE fix, SSRF, DOM XSS, etc.)
2. **A new identity** — Trove, "Save things you care about", warm consumer-friendly visual design
3. **A frontend rewrite** to htmx + Tailwind CSS + Alpine.js (server-rendered, no Node)
4. **A fresh repo** with clean git history under `afk1997`, public, MIT-licensed, with proper attribution to the original author

## Goals

- Eliminate the argument-injection RCE, SSRF, DOM XSS, error-leak, and missing-headers gaps
- Restore YouTube downloads via `--cookies-from-browser` env opt-in + auto-update of yt-dlp
- Stop unbounded memory and disk growth
- Fix filename truncation, audio-fallback honesty, timeout-leak, `request.json` None, multi-line stdout, friendlyError, and stale yt-dlp issues
- Land a new visual identity that feels like a consumer app, not a dev tool
- Keep deploy simple: single Dockerfile, single Python process, no Node runtime
- Fresh git history under `afk1997`, no inherited commits

## Non-goals (Phase 2 or later)

- PWA manifest + service worker + install prompt
- Android APK via Trusted Web Activity / Bubblewrap
- Native iOS / React Native
- Multi-user accounts, history, persistent DB, login system
- HTTPS / TLS termination (deploy behind a reverse proxy)
- Custom logo design (use a clean wordmark this phase)

Each Python module is < 200 LoC. `app.py` is thin — request parsing, validator/decorator wiring, JobManager calls, response rendering.

### Why this stack

- **htmx:** server returns HTML fragments, htmx swaps them in place. The current "poll every 1s, manually re-render the card" loop becomes one attribute. ~150 lines of frontend JS evaporate. Tiny (~14kb), no build, very stable.
- **Tailwind standalone CLI:** one binary, no Node, no npm. `tools/tailwindcss -i styles/input.css -o static/app.css --minify` produces a tree-shaken CSS file. Modern utility-first styling with zero ecosystem churn.
- **Alpine.js:** for the small bits htmx alone can't do (dark-mode toggle persisted in localStorage, copy-to-clipboard, dropdown). 15kb, no build.
- **No JS framework, no bundler, no Node runtime.** CSS builds at deploy time only; the running container needs only Python.

## Key design decisions

| Decision | Choice | Rationale |
|---|---|---|
| Job TTL | 1 hour, configurable via `TROVE_JOB_TTL_SECONDS` | Bounded memory + disk |
| Sweeper cadence | every 5 min | Cheap |
| Token auth | opt-in via `TROVE_TOKEN` env | Default-off matches localhost case |
| Docker `HOST` | 127.0.0.1 | Today's `0.0.0.0` is unsafe given unauth API |
| URL validation | scheme allowlist + IP block list | Refuse `file://`, loopback, RFC1918, link-local |
| Argument injection | `--` separator before URL in every subprocess call | Standard fix; pytest regression |
| Cookies | env-opt-in `TROVE_COOKIES_FROM_BROWSER=safari\|chrome\|firefox\|brave\|edge` | Required for YouTube right now |
| yt-dlp updates | `pip install -U yt-dlp` on every `trove.sh` start | Extractor breakage is the #1 failure mode |
| Concurrency | `ThreadPoolExecutor(max_workers=4)`, `TROVE_MAX_WORKERS` | Stops fork-bomb DoS; overflow → 503 |
| Rate limit | in-process token bucket per IP, 30/min default; `TROVE_RATE_LIMIT=0` disables | Cheap defense |
| Cancellation | `POST /api/job/<id>/cancel` + `sendBeacon` on unload | sendBeacon-friendly |
| Error reporting | category enum to client; raw stderr to server log only | Stops filesystem-path leaks |
| Dark mode | toggle persisted to `localStorage`; respects `prefers-color-scheme` on first visit | Consumer expectation |
| Inline scripts | use a per-request CSP nonce; `script-src 'self' 'nonce-...'` | No `'unsafe-inline'` |
| Theme | warm coral accent, Inter, light-default | Consumer-friendly, not dev-tool |

### Error category enum

`unsupported_url`, `private_or_unavailable`, `geo_restricted`, `rate_limited`, `auth_required`, `network`, `timeout`, `unknown`. Template renders human copy from category.

### Filename sanitization

20-char cap → 150 chars. Strip control chars, NFC-normalize unicode, strip leading/trailing dots and spaces. Fall back to `job_id` if the result is empty.

### Audio-mode honesty

If MP3 was requested and the postprocessor didn't actually produce a `.mp3`, the job ends in `error` with a clear message. No more silently serving `.webm` named `.mp3`.

### Misc fixes (rolled into the relevant module)

- **Orphan files on `TimeoutExpired`** — `runner.py` cleans up matching `glob` entries on every exit path.
- **`request.json` None** — guarded with `silent=True` and explicit 400.
- **`yt-dlp -j` multi-line stdout** — defensive `splitlines()[0]` parse with a warning log.
- **Job-ID width** — keep `uuid4().hex[:10]` (40 bits) for now; only meaningful within a TTL window.

## Endpoints

| Endpoint | Method | Returns | Notes |
|---|---|---|---|
| `/` | GET | base.html | redesigned |
| `/api/info` | POST | JSON | stable scriptable API |
| `/api/info-card` | POST | HTML fragment (`card.html`) | **new** — htmx-friendly; what the UI calls |
| `/api/download` | POST | HTML fragment (card) | starts job + returns updated card |
| `/api/status/<id>` | GET | HTML fragment (card) | htmx polls; returns full card |
| `/api/file/<id>` | GET | binary stream | unchanged shape; auth-checked; updates `last_accessed` |
| `/api/job/<id>/cancel` | POST | HTML fragment (card) | **new** — kills subprocess or removes done job |

JSON shape on `/api/info` and `/api/status` retained for any external callers; the UI uses the HTML-fragment variants exclusively.

## Frontend rewrite (templates/index.html → htmx + Tailwind)

The existing 700-line single-file template gets replaced by:

- `templates/base.html` — `<head>`, Tailwind-built CSS, vendored htmx + Alpine, dark-mode bootstrap (runs before paint to avoid flash).
- `templates/index.html` — page layout (input, format toggle, fetch button, queue container).
- `templates/partials/card.html` — a single job card rendered server-side. Contains the htmx polling attributes when status is `downloading`.
- `templates/partials/card_list.html` — the queue container (htmx target for `/api/info-card`).

Polling becomes:

```html
<div hx-get="/api/status/{{ job.id }}" hx-trigger="every 1s" hx-swap="outerHTML">
  ...current state rendered server-side...
</div>
```

Cancel-on-unload becomes a tiny vendored snippet:

```js
window.addEventListener('beforeunload', () => {
  for (const id of activeJobIds())
    navigator.sendBeacon(`/api/job/${id}/cancel`);
});
```

Dark mode lives in 8 lines of Alpine. No `cardData`, no `parseUrls`, no `renderCard` — Jinja + htmx do all the rendering.

## Security headers

`safety.py` attaches headers via Flask `after_request`:

```
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Referrer-Policy: no-referrer
Content-Security-Policy:
  default-src 'self';
  img-src 'self' https: data:;
  style-src 'self' 'nonce-{{nonce}}' https://fonts.googleapis.com;
  font-src 'self' https://fonts.gstatic.com;
  script-src 'self' 'nonce-{{nonce}}';
  connect-src 'self';
  frame-ancestors 'none';
```

A per-request nonce sits in `g.csp_nonce`; templates use `<script nonce="{{ g.csp_nonce }}">` for the dark-mode bootstrap and any other inline scripts.

## Deploy

- **`Dockerfile`** is multi-stage:
  - Stage 1 (`builder`): downloads Tailwind binary, runs CSS build, vendors htmx + Alpine.
  - Stage 2 (`runtime`): copies built CSS, vendored JS, app code; installs ffmpeg + Python deps; runs as non-root.
- **Image size target:** < 200 MB (python:3.12-slim + ffmpeg + yt-dlp + Flask).
- **Default port:** 8899.
- **Default `HOST`:** 127.0.0.1 inside the container.
- **Recommended hosts** (documented in README): Fly.io machines, Railway, Render, self-hosted VPS behind nginx/Caddy.

## Acceptance criteria for Phase 1

1. `python -m pytest` is green.
2. **RCE blocked:** `curl --data '{"url":"--exec=touch /tmp/pwned"}' http://127.0.0.1:8899/api/info` returns 400 and `/tmp/pwned` does not exist.
3. **TTL works:** after `TROVE_JOB_TTL_SECONDS=10` and 15s of idle, both `jobs` dict and `downloads/` directory are empty.
4. **Docker default safe:** `docker run -p 8899:8899 trove` exposes only `127.0.0.1` inside the container.
5. **YouTube works with cookies:** with `TROVE_COOKIES_FROM_BROWSER=safari` and a logged-in Safari session, downloading a YouTube URL succeeds.
6. **Token auth:** with `TROVE_TOKEN=abc123`, all `/api/*` requests without `Authorization: Bearer abc123` return 401.
7. **Cancel on tab close:** closing the browser tab during a download cancels the worker within ~5s.
8. **CSP clean:** response headers contain `script-src 'self' 'nonce-...'` with no `'unsafe-inline'`.
9. **Mobile:** at 375px viewport, every interactive element is ≥ 44px tall.
10. **Lighthouse:** mobile Performance ≥ 90, Accessibility ≥ 95, in both light and dark.
11. **Repo state:** `github.com/afk1997/trove` is public, MIT-licensed, README has the attribution footer, contribution graph shows only `afk1997`.

## Risks & open questions

- **Cookies require a real logged-in browser session on the host.** Documented in README. Without it, YouTube continues to 403 — that's a Google policy, not fixable on our end.
- **Tailwind binary size** (~50 MB per platform): downloaded on first build, gitignored. Acceptable.
- **htmx + screen readers:** the queue container gets `aria-live="polite"` so swapped fragments are announced.
- **Inter via Google Fonts CDN** is a third-party dep. Acceptable for Phase 1; self-hosted variant is a future swap if desired.
- **Cancellation race:** a job can complete between `cancel` arriving and the kill firing. Harmless — file stays, job marked done.
- **Rate limit per-process:** multi-process deployment (gunicorn workers) defeats the in-process limiter. Documented as "single-process only"; Redis-backed limiter is a Phase 2 item if we ever need it.
