§ 01 · Palette

Two inks on cream stock

Trove is printed in two inks on a single paper. Every other "color" you see is the product of those two inks reacting to grain and halftone overlay. Saturation and chroma stay flat — depth comes from offset shadows and registration shift, never from gradients.

paper.
#F1E6CC
Page background only. Always paired with the dot grain pattern.
light.
#FEF7E3
Cards, plates, raised surfaces, input fields.
teal ink.
#1A3540
Primary text, borders, dividers, default UI fill.
flo. red.
#FF5728
Accents, stamps, primary CTA, errors, registration offset.
forest.
#1F7A3F
Single exception to two-ink rule. Used only for the "✓ saved" stamp and the saved file path.

Rules

  • Two inks. The page must read as if printed with one paper stock and two passes of ink.
  • Errors reuse --orange. There is no separate red.
  • No gradients. No blurred shadows. No semitransparent orange — use halftone for tints.
  • Paper grain is always present. Texture is the brand.

Tokens

--paper:  #F1E6CC;   /* page bg */
--light:  #FEF7E3;   /* cards / plates */
--teal:   #1A3540;   /* primary ink */
--orange: #FF5728;   /* accent ink */
--forest: #1F7A3F;   /* saved-state only */

--halftone:        rgba(255, 87, 40, 0.04);
--offset-shadow:   rgba(26, 53, 64, 0.18);
--shadow-card:        4px 4px 0 var(--teal);
--shadow-card-orange: 4px 4px 0 var(--orange);
--shadow-stamp:       2px 2px 0 var(--teal);
--shadow-stamp-3:     3px 3px 0 var(--teal);
§ 02 · Texture

Paper grain & halftone

The page background is built from two stacked layers: a five-layer radial-gradient dot pattern (the paper grain), and a fixed-position halftone overlay applied with mix-blend-mode: multiply (the orange "ink" prints over everything). Both stay attached to the viewport so they don't scroll.

body {
  background: var(--paper);
  background-image:
    radial-gradient(circle at 12% 18%, rgba(26, 53, 64, 0.05) 0.5px, transparent 1px),
    radial-gradient(circle at 78% 38%, rgba(26, 53, 64, 0.06) 0.5px, transparent 1px),
    radial-gradient(circle at 32% 76%, rgba(26, 53, 64, 0.05) 0.5px, transparent 1px),
    radial-gradient(circle at 88% 88%, rgba(26, 53, 64, 0.06) 0.5px, transparent 1px),
    radial-gradient(circle at 50% 50%, rgba(26, 53, 64, 0.04) 0.5px, transparent 1px);
  background-size: 4px 4px, 5px 5px, 6px 6px, 4px 4px, 7px 7px;
  background-attachment: fixed;
}
body::before {
  content: '';
  position: fixed; inset: 0;
  background-image:
    repeating-radial-gradient(circle at 0 0, var(--halftone) 0 0.8px, transparent 0.8px 6px);
  mix-blend-mode: multiply;
  pointer-events: none;
  z-index: 100;
}

§ 05 · Buttons

Brass stamps

§ 11 · Motion

Six beats

All motion is CSS-only. Every keyframe and infinite loop is killed by a single @media (prefers-reduced-motion: reduce) block. No spring. No bounce. No parallax. The page is paper, not an app.

1 · Card-in

280ms · cubic-bezier(.22,1,.36,1)

New clipping translateY(-6px) + rotate(-0.6°) → settles. Reads like paper landing.

2 · Stamp slam ★

260ms · cubic-bezier(.16,1,.3,1) + 400ms ink-burst

Saved stamp scale 2.2 → 1, rotate 8° → 2.5°, with a green ink-burst ripple. The viral moment.

3 · Halftone scan

1.4s · linear · infinite

Used for indeterminate loading; replaced by determinate fill once total bytes are known.

4 · Stamp press

150ms hover · 80ms press

Hover shadow 3 → 4px (anticipation). Press collapses shadow + translates +3,+3. Bounces back on release.

5 · Toggle ink-fill

220ms · cubic-bezier(.4,0,.2,1)

Active pill text/background swap with smooth 150ms color transition.

6 · Breathing arrow

3s · ease-in-out · infinite

Empty-state arrow breathes 3px up/down with opacity 0.55→0.85.

Reduced-motion fallback

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
§ 12 · Voice

Plainspoken, off-kilter

Lowercase wherever possible. Uppercase only for mono stamps. Verbs are concrete; the metaphor lives in nouns. Never SaaS.

"a saving machine for the modern web."

Plain, slightly off-kilter, reads like a zine editor's note.

"Effortlessly archive your favorite content from across the web!"

Marketing voice. Over-explaining. AI-startup hype. Death.

SAVE ↗

Verb is concrete. Single arrow. Slight rotation = stamp.

Get Started Free →

SaaS verb. Implies a signup. Trove has no account.

"nothing here yet. paste a link."

Empty states are calm. Lowercase. Periods, not exclamation marks.

"Your trove is empty! 🎯 Get started by pasting your first link!"

Emoji. Two exclamations. "Get started." All cardinal sins.

§ 14 · Non-negotiables

The hard rules

  • Riso is a brand-only direction. The interaction model — paste, toggle, save, watch the card — never gets clever.
  • One paste box. One toggle. One button. No required tooltips.
  • Two inks (plus paper). Forest green is the only exception, and only on "✓ saved".
  • Paper grain is always present. Halftone overlay is always present. Texture is the brand.
  • Hard offset shadows only — never blurred.
  • No emoji. No exclamation marks. No SaaS verbs.
  • No gradients on UI. No spring or bounce easing. No parallax.
  • WCAG AA contrast verified for every foreground/background pair.
  • prefers-reduced-motion: reduce kills every animation in a single block.
  • Mobile uses the same layout, scaled — never a separate "mobile site".
  • Tap targets ≥ 44px on viewports ≤ 480px.
